## 💻 Sobre o Projeto
O **Social Recomeçar** é a plataforma web oficial do departamento social da Comunidade Cristã Recomeçar. Este projeto foi desenvolvido para facilitar a captação de doações, apresentar os valores da instituição e, principalmente, oferecer um canal direto e simplificado para a indicação de famílias e pessoas em situação de vulnerabilidade. O site possui uma interface moderna, acolhedora e 100% responsiva.

## 🚀 Funcionalidades e Destaques Técnicos
O foco do desenvolvimento foi garantir acessibilidade, rapidez e facilidade de comunicação para os usuários:

- **📱 Design Mobile-First & Responsivo:** Layout adaptável para qualquer tamanho de tela, com botões bem dimensionados para usabilidade em dispositivos móveis.
- **💬 Integração Dinâmica com WhatsApp:** O formulário de indicação captura os dados inseridos (nome, indicado, contato e situação) e utiliza JavaScript para formatar e redirecionar automaticamente uma mensagem estruturada para a API do WhatsApp dos responsáveis.
- **✨ UI/UX Aprimorada:** Efeitos de *hover*, cartões de informação flutuantes e botões de ação fixos (Sticky e Floating Buttons) que acompanham a navegação sem atrapalhar a leitura.
- **🎨 Identidade Visual Integrada:** Utilização de gradientes modernos, sombras suaves e recorte dinâmico via CSS (Border-radius) para a aplicação perfeita da logo da instituição.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica e formulários interativos.
- **CSS3:** Estilização avançada utilizando Flexbox/Grid, variáveis globais (`:root`), Media Queries e animações de transição.
- **JavaScript (ES6+):** Captura de valores do DOM, validação simples de campos e construção de URLs dinâmicas para a API de comunicação externa.
- **Hospedagem:** Deploy contínuo configurado via GitHub e hospedado na plataforma **Netlify**.

## 💡 O que aprendi com este projeto
Durante o desenvolvimento desta aplicação, consegui aprimorar minhas habilidades em:
- Criação de interfaces focadas em **Mobile-First** e usabilidade em telas menores.

## ⚙️ Como testar o projeto localmente

1. Clone ou baixe a pasta do repositório.
2. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador (ou utilize a extensão *Live Server* no VS Code).
3. Teste o formulário de indicações na seção "Indicar Família ou Pessoa" para ver a lógica de redirecionamento dinâmico em ação.
